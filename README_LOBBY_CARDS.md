# 로비 강화 카드 — 3장 중 1장 고르기 + 영구 저장

로비 제단 가챠에 GPT 버전 게임의 좋은 점을 얹었습니다.
**등급(하급~전설·혼돈), 등장 확률, 등급별 수치, 디버그 패널의 실시간 조절은 그대로**입니다.

> Unity 6000.6.5f1에서 컴파일 오류 0, 로비 → 전투(사망 정산) → 로비 → 플레이 재시작까지 직접 돌려 확인했습니다.

## 바뀐 흐름

| | 예전 | 지금 |
|---|---|---|
| 제단 상호작용 | 확인창 "100G를 소모하여 뽑으시겠습니까?" → 골드 차감 → 카드 3장 | **카드 3장이 바로 보임** (비용·보유 골드 표시) |
| 골드 | 카드를 보기 전에 냄 | **고를 때만** 냄. 마음에 안 들면 `건너뛰기`(ESC) — 골드 그대로 |
| 제시된 3장 | 열 때마다 새로 뽑음 | **저장됨**. 창을 닫았다 열거나 게임을 다시 켜도 같은 3장 |
| 횟수 | 골드만 있으면 무제한 | **로비 방문 1번에 1장**. 전투 정산(사망·클리어) 때 다시 열리고 새 3장 |
| 비용 | 100G 고정 | 100G + **25G × 지금까지 고른 장수** (인스펙터 `Cost Step`) |
| 강화 유지 | static 변수 — 게임을 끄면 사라짐 | **progress.json에 저장** — 게임을 꺼도 남고 계속 쌓임 |
| 혼돈 등급 | 고르는 순간 범위 안에서 결정 | 그대로 (결과 창에 "혼돈의 주사위 → 공격력 -3"처럼 보여 줌) |

카드 창 위에 제목·비용, 아래에 쌓인 강화·안내 문구와 버튼이 붙습니다. **씬·프리팹은 건드리지 않았고** 실행할 때 만들어 붙입니다 (버튼은 확인창의 '취소' 버튼을 본뜸).

## 저장

- 파일: `Application.persistentDataPath/progress.json`
  (윈도우: `C:\Users\이름\AppData\LocalLow\<회사명>\<제품명>\`)
- 들어 있는 것: 제단에 놓인 3장(스탯·등급), 이번 방문에 골랐는지, 고른 카드 목록(스탯·등급·실제 수치·비용), 정산까지 간 전투 수
- 임시 파일에 다 쓴 뒤 한 번에 바꿔 끼우고 직전 파일은 `.bak`으로 남김 → 쓰다가 꺼져도 깨지지 않음. 본 파일이 깨졌으면 `.bak`에서 읽음
- 고를 때 순서: **기록 저장 → 성공하면 골드 차감 → 플레이어에 반영**. 저장이 실패하면 아무것도 바뀌지 않음
- **골드는 예전 그대로 PlayerPrefs `PlayerGold`** (디버그 패널이 직접 쓰고 있어서 옮기지 않음)
- 타이틀의 데이터 초기화(`MenuManager.ResetAllGameData`)가 progress.json도 지움

## 플레이어에 적용되는 방식

고른 카드 목록을 **씬마다 그 씬 플레이어의 기본값 위에 순서대로 다시 쌓습니다** (`PlayerMovement.Start` → `ApplyPermanentCards`).
하한·정수 처리는 `ApplySingleBuff`와 같습니다 (공격력·체력 최소 1, 이동 속도·점프력 최소 1, 공격력·체력은 정수로 잘림).
그래서 로비 플레이어와 전투 플레이어의 기본값이 달라도 각자 맞게 더해집니다.

디버그 패널로 스탯을 직접 덮어쓴 경우(`saved*` static)는 그 값이 우선입니다 — 예전처럼 그 판 동안만 유지.

## 테스트하는 법

- **BuffGachaManager 인스펙터 ⋮ 메뉴**
  - `⭐ [테스트] 이번 방문 카드 다시 열기` — 전투 없이 다시 고를 수 있게 (새 3장)
  - `⭐ [테스트] 로비 카드 기록 전부 지우기` — progress.json 삭제 (씬을 다시 시작하면 기본 스탯)
- 골드는 예전처럼 디버그 패널(F1)이나 `BattleStatsManager`의 `⭐ 인스펙터 값으로 골드 덮어쓰기`

확인한 것: 처음 열기(100G) → 건너뛰기 → 다시 열어도 같은 3장 → ESC로 닫힘(일시정지 메뉴 안 뜸) → 구매(전설 이동 속도 +1.0) → 다시 열면 "이미 골랐습니다" → 전투 씬 플레이어 이동 속도 6.0 → 사망 정산 → 로비에 새 3장·비용 125G → 골드 부족 안내 → 혼돈 구매(공격력 -3) → 플레이 재시작해도 기록 유지.

## 기획 확인이 필요한 것

| 내용 | 지금 구현 |
|---|---|
| 비용 증가 폭 | 장당 +25G (`Cost Step`). 0으로 두면 예전처럼 고정 |
| 건너뛰기 | 창만 닫음 — 같은 방문 안에서는 다시 열어 고를 수 있음 (같은 3장) |
| 전투 중 일시정지 메뉴로 로비에 가면 | 정산이 없으므로 카드도 다시 열리지 않음 |
| 쌓인 강화 문구 | 고른 카드 수치의 단순 합 (혼돈 마이너스가 하한 1에 걸려 실제 스탯과 다를 수 있음) |
| GPT 버전의 포션 카드(회복량·개수), 궁극기 계승 | 이번에는 넣지 않음 — 스탯 종류와 디버그 패널 표를 늘려야 해서 따로 정하는 게 나음 |
